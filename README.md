# Benchmark Analysis — Thesis Reproducibility Package

This repository contains the analysis code, saved results, and final figures for the bachelor's thesis on ranking robustness, diversity, and stability in multi-task benchmarks.

## Research focus

The project studies how benchmark rankings change when benchmark composition is perturbed. The repository contains analyses based on:

- leave-one-dataset/task-out (LODO) perturbations;
- Kendall's tau and related rank-comparison measures;
- local rank-movement measures;
- winner changes;
- random benchmark subsets;
- coordinated multi-dataset removal;
- descriptive dataset-influence diagnostics;
- performance-gap / pairwise-reversal analyses;
- cross-benchmark LODO comparisons for TabArena, GLUE, OpenLLM, and ImageNet;
- BenchBench diversity and sensitivity measures.

## Canonical execution path

The intended entry point is:

```text
Code/analysis/run_current_pipeline.py
```

The consolidated thesis figures are generated by:

```text
Code/analysis/plot_final_thesis_figures.py
```

Canonical generated outputs live under:

```text
results/
```

Do not treat files under `docs/original_scripts/` as the current execution path. They are preserved historical versions.

## Safe report check

For a final consistency check, run:

```powershell
python Code/analysis/run_current_pipeline.py --report
```

The report mode is intended to be read-only with respect to the analysis outputs: it validates the saved result tables and checks that all nine final thesis figures are present. It does not launch the expensive benchmark searches.

Running without arguments currently has the same report behavior:

```powershell
python Code/analysis/run_current_pipeline.py
```

## Recompute derived analyses

To explicitly regenerate the configured non-exhaustive analyses and report plots:

```powershell
python Code/analysis/run_current_pipeline.py --refresh
```

## Expensive analyses

Long-running recomputation is protected by the pipeline. A single expensive stage must be selected deliberately, for example:

```powershell
python Code/analysis/run_current_pipeline.py --stage dataset_search --expensive
```

The complete configured pipeline requires an explicit permission flag:

```powershell
python Code/analysis/run_current_pipeline.py --full --expensive
```

Existing saved results should normally be reused for submission verification; a full expensive recomputation is not required merely to run `--report`.

## Important interpretation safeguards

### Dataset influence

Dataset influence is a **descriptive ranking of observed sensitivity dimensions**. It should not be described as a causal estimate or as proof that a dataset causes instability.

### Performance gap

The performance-gap analyses examine associations between winner–runner-up gaps and ranking instability. They do not establish that a small gap causes instability.

For GLUE, pairwise reversal rate is a local measure of how often a particular model pair changes order under LODO. It is not a replacement for a global ranking statistic such as Kendall's tau.

### Coordinated removal

Joint/removal search results describe observed failure boundaries under the tested removal search. They should not be interpreted as probabilities over the full perturbation space, especially for targeted beam-search depths.

### Diversity versus sensitivity

BenchBench diversity/sensitivity plots are descriptive cross-benchmark comparisons. A small number of benchmark-level observations is not sufficient evidence for a universal causal relationship.

### Score versus Elo

The primary reproducible Score-vs-Elo comparison is the complete 51-dataset TabArena LODO analysis. The older 93-shared-subset comparison is not reproducible from the current committed coordinated-removal artifacts and should not be used as a primary quantitative claim.
