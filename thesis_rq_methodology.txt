Research Questions and Methodology

1. Research Questions (Short Version)


RQ1: How stable are model rankings in machine learning benchmarks under task perturbations?

RQ2: To what extent do individual tasks influence the overall ranking of models?

RQ3: How does the choice of aggregation method affect leaderboard rankings and their stability?


2. Methodology (Short Version)

1. Select benchmark dataset(s) (e.g., TabArena, optionally CARP-S)

2. Compute baseline rankings using:
   - Mean aggregation
   - (Optional) Rank-based aggregation

3. Perform Leave-One-Task-Out (LOTO):
   - Remove one task at a time
   - Recompute rankings

4. Measure ranking changes using:
   - Rank correlation (Kendall Tau or Spearman)
   - Top-k overlap (e.g., top-5 or top-10)

5. Compute Task Influence Score:
   - Measure ranking change caused by removing each task

6. Compare aggregation methods:
   - Repeat steps 2–5 for different aggregation schemes


3. Methodology (Detailed Version)

3.1 Data Selection

The analysis is conducted on large-scale machine learning benchmark datasets such as TabArena and optionally CARP-S. These benchmarks consist of multiple tasks and corresponding model performances.

The goal is to study how the composition of tasks influences the resulting leaderboard rankings.

3.2 Baseline Leaderboard Construction

First, a reference leaderboard is constructed using standard aggregation methods.

- Mean aggregation: The average performance of each model across all tasks is computed.
- Optional: Rank-based aggregation (e.g., Borda count), where models are ranked per task and aggregated based on ranks.

This baseline ranking serves as the reference point for all further comparisons.

3.3 Task Perturbation via Leave-One-Task-Out (LOTO)

To analyze stability, a controlled perturbation is applied:

- For each task in the benchmark:
  - Remove the task from the dataset
  - Recompute the aggregated leaderboard

This results in a set of modified rankings, each corresponding to the removal of a single task.

Purpose:
This step evaluates how sensitive the leaderboard is to small changes in benchmark composition. If rankings change significantly, the benchmark is considered unstable.

3.4 Measuring Ranking Stability

To quantify differences between the baseline ranking and perturbed rankings, the following metrics are used:

- Rank Correlation (Kendall Tau or Spearman):
  Measures the similarity between two rankings. High correlation indicates stability.

- Top-k Overlap:
  Measures how many models remain in the top-k positions (e.g., top-5 or top-10).
  This captures practical relevance, as users often focus on top-performing models.

Purpose:
These metrics provide a quantitative measure of how much rankings change under perturbation.

3.5 Task Influence Analysis

For each task, a Task Influence Score is computed based on the change in ranking after its removal.

Possible definitions:
- 1 - rank correlation
- Average rank shift across models

Purpose:
This allows identification of:
- Critical tasks: removal causes large ranking changes
- Redundant tasks: removal has little effect

This step provides insight into the internal structure of the benchmark.

3.6 Aggregation Method Comparison

To study the effect of aggregation:

- Repeat the full analysis (baseline + LOTO + stability metrics) using different aggregation methods:
  - Mean aggregation
  - Rank-based aggregation

Purpose:
This evaluates whether the choice of aggregation method significantly affects:
- The resulting rankings
- Their robustness to perturbations

This connects the empirical analysis to theoretical results from multi-criteria decision-making.

3.7 Optional Extension: Multi-Task Removal

If time permits:

- Randomly remove multiple tasks (e.g., 2–3 at a time)
- Repeat the process multiple times

Purpose:
This tests robustness under stronger perturbations and provides a more comprehensive view of benchmark stability.
